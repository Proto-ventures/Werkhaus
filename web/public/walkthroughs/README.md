# Walkthrough pictures

Screenshots and short recordings for the connection walkthroughs, named to
match the `media` field of each step in `werkhaus/contract/catalog.py` — e.g.
`supabase/03-generate.png`.

These are a **slot, not a dependency**. Every step must be followable from its
words alone (there is a test), and the page hides an image that isn't here. So
this directory can stay empty, and filling it later needs no code change.

Provider interfaces change. When one does, the step text is what has to be
corrected first; a stale picture is a smaller problem than stale instructions.
